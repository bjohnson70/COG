# COG Document Catalog

This is the authoritative inventory of controlled documents in the Common
Operations Guide (COG).

[README.md](README.md) provides human-oriented repository navigation. This
catalog provides the authoritative controlled-document inventory. Inclusion in
this catalog does not by itself make an incomplete document Active; each status
reflects the document's actual lifecycle state.

The identifier `COG-DOCUMENT-CATALOG` identifies this catalog only. It does not
establish a universal COG Document ID taxonomy.
